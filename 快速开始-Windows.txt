佩丽卡监督 —— Windows 快速开始
====================================

一个住在微信群里的《明日方舟：终末地》佩丽卡机器人：
剧情问答带出处、抖音链接自动解析、早晚问好、每周群统计播报。

------------------------------------
一、你需要准备
------------------------------------
1. Windows 10/11 64 位
2. Python 3.10+（python.org 下载，安装时勾选 Add to PATH）
3. 一个 DeepSeek API key（https://platform.deepseek.com 注册充值，
   群机器人日常用量每月几块钱足够）
4. 一个微信小号（有被封号风险，务必不要用大号！）
5. 微信 4.1.10.27 安装包（本包不附带，请自行搜索下载；
   新版微信会覆盖旧版，装完记得关闭「自动更新」）

------------------------------------
二、三步安装
------------------------------------
1. 双击「安装.bat」——自动建虚拟环境、装依赖、生成 .env
2. 用记事本打开 .env，填入你的 DEEPSEEK_API_KEY
3. 数据库二选一：
   A（推荐）到本项目 GitHub Release 下载「pelica.db 预构建包」，
      解压出 pelica.db 放进 data\ 文件夹
   B 自行获取 PRTS-Terrachive 语料（github.com/MizeTry/PRTS-Terrachive），
      把 release 目录放进 corpus\releases\，然后执行：
      .venv\Scripts\python.exe scripts\build_db.py

没装微信也可以先双击「mock体验.bat」在本机体验完整对话。

------------------------------------
三、微信接入（上线到真群）
------------------------------------
1. 安装微信 4.1.10.27 并登录机器人小号
2. 把本包 hook\ 目录里的 version.dll 复制到微信安装目录
   （与 Weixin.exe 同一文件夹，常见位置见下）
   - D:\WeChat\Weixin\
   - C:\Program Files\Tencent\Weixin\
   version.dll 来自开源项目 WeChat-Hook（github.com/aixed/WeChat-Hook）
3. 双击「启动机器人.bat」——它会拉起微信，等登录后自动上线
4. 日志出现「WeChat-Hook 桥接激活」即成功，去群里 @佩丽卡监督 试试

常见位置提示：如果微信升级过版本，hook 会失效——把微信降回 4.1.10.27
即可；也可以对目录 %USERPROFILE%\AppData\Roaming\Tencent\xwechat\update\patch
设置拒绝写入来阻止自动升级。

------------------------------------
四、常用配置（.env）
------------------------------------
BRIDGE_MODE=wxhook          上线真群用 wxhook；体验用 mock
GROUP_WHITELIST=群名1,群名2  只在这些群说话；留空=所有群（不建议）
GREETING_MORNING_TIME=07:30 早问好时刻
GREETING_NIGHT_TIME=23:00   晚问好时刻
WEEKLY_REPORT_TIME=18:00    周五统计播报时刻
DOUYIN_KEEP_HOURS=48        抖音缓存保留时长（小时）
